# 🧮 NSP

> Implementation of a graph matching algorithm using network flow for bipartite and weighted edge graphs with maximum and minimum capacity.

## 🚀 **Overview**

Solving one Nurse Scheduling Problem (NSP) using graphs.

## 🛠️ **Technologies and Tools**

- **Python**: Main programming language
- **Matplotlib**: Plot graphs
- **Networkx**: Creating and manipulating graphs
- **Jupyter Notebook**: Interactive development
- **Poetry**: Dependency and environment management
- **Docker** + **DevContainers**: Isolated, configurable environments

## ⚙️ **Prerequisites**

Before you begin, make sure you have the following installed:

- [Docker](https://www.docker.com/)
- [Dev Containers extension for VS Code](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)

## 🧪 **Getting Started**

1. **Clone the repository:**

    ```bash
    git clone https://github.com/your-username/NSP.git
    cd NSP
    ```

2. **Open with VS Code Dev Containers:**

    - Open the folder in **Visual Studio Code**.
    - Press `F1` (or `Ctrl+Shift+P`), then select:
        ```
        Dev Containers: Reopen in Container
        ```

3. **Done! ✅**

## 📚 **Additional Notes**

- This repository is configured to provide a consistent and isolated development environment, ideal for collaborating on academic or professional projects related to numerical methods.
